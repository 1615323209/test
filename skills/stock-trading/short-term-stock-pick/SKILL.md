# Short-Term Stock Pick（短线选股）

## 选股标准（适配2万资金短线策略）

```
流通市值：50亿 ~ 500亿（太小流动性差，太大启动慢）
日均成交额：> 3亿（保证能进能出）
主力资金：近3日净流入为正
技术形态：满足以下至少2项：
  - 价格站上10日均线
  - 今日涨幅 > 2%（强势）
  - 成交量 > 5日均量 1.5倍（放量）
  - 近5日内出现过涨停（强势股逻辑）
止损空间：当前价距近期支撑位 < 5%（止损位清晰）
```

### ⛔ 一票否决条件（满足任一 → 直接排除，不做例外）

```
1. 所在板块当日主力净流出 > 30亿 → 排除（板块资金在撤退，个股逆势无法持续）
2. 市场评分 = 3（临界值）且板块当日净流入为负 → 排除（弱市不做逆势股）
3. 今日涨幅已超 5% → 排除（不追高）
4. 今日跌破10日均线 → 排除（技术走坏）
5. 个股当日主力净流入为正但板块净流出超50亿 → 排除（资金护盘不可信）
```

> 📌 教训（2026-07-07）：湖南白银个股主力净流入，但小金属板块净流出-64亿，属于典型逆势个股。
> 弱市（评分=3）中此类股次日大概率补跌，应在一票否决阶段直接排除。

## 执行步骤

1. 从 market-scan 拿到热点板块名单（前3）
2. 请求异动接口，筛选出属于热点板块且满足流通市值/成交额条件的股票
3. 对每只候选股请求K线，验证技术形态（是否站上10日均线、量比）
4. 按以下权重综合评分排序

## 评分权重

| 条件 | 权重 |
|------|------|
| 属于今日资金净流入前3板块 | 40% |
| 今日成交量 > 5日均量1.5倍 | 20% |
| 价格站上10日均线 | 20% |
| 近5日内有涨停记录 | 20% |

## 输出格式

```
===== 今日短线候选标的 =====
板块方向：XX板块（净流入+XX亿）

候选股票（最多3只）：

1. 股票名称（代码）
   现价：XX元 | 今日涨幅：+X.X%
   流通市值：XX亿 | 今日成交：XX亿
   主力净流入：+XX万
   技术形态：站上10日线 ✓ | 放量 ✓ | 近期涨停 ✓
   建议买入区间：XX ~ XX元
   止损位：XX元（-5%）
   第一目标：XX元（+8%）
   第二目标：XX元（+15%）
   评分：X分

操作提示：
  单票仓位上限 10,000元（总资金50%）
  买入后立即设置5%止损
```

## 注意事项

- 竞价阶段不追涨，等开盘30分钟后方向确认再进
- 若候选股当日涨幅已超5%，标注"今日不追，等回调"
- 若未找到符合条件的股票，输出"今日无合适标的，空仓观望"
- 所有建议仅供参考，最终决策由用户自行判断

## 已知 API 坑

### push2.eastmoney.com 反爬问题（2026-07 实测）
- `/api/qt/stock/get`（个股实时行情）被反爬拦截，server closed abruptly，返回空
- `/api/qt/clist/get`（股票列表/异动）**未验证**，同域名有反爬风险，若调用失败：
  - 实时行情改用腾讯接口：`https://qt.gtimg.cn/q={sh/sz}{代码}`
  - 异动数据可改用东方财富 PC 端行情接口：`https://quote.eastmoney.com/center/gridlist.html`（需解析页面）
  - 或直接从 K 线数据推算量比（近日成交量 / 5日均量）
- `push2his.eastmoney.com`（K 线历史）和 `data.eastmoney.com`（板块资金）**正常可用**，无反爬
