# Stock Quick Analysis（个股快速评估）

## 输入
股票代码（6位），例如 000069、600519

## 确定市场前缀
- 6开头 → 沪市，secid前缀 = 1
- 0/3开头 → 深市，secid前缀 = 0
- 示例：000069 → secid=0.000069，600519 → secid=1.600519

## 数据源（全部来自 go-stock-dev 已验证接口）

### 1. 实时行情（腾讯行情，无需鉴权，稳定可靠）

市场前缀：沪市代码用 sh，深市用 sz
示例：600519 → sh600519，000069 → sz000069

```
GET https://qt.gtimg.cn/q={市场前缀}{代码}
Headers:
  Referer: https://gu.qq.com/
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
```

返回格式（~分隔，按下标取值）：
v_sh600519="1~股票名~代码~最新价~昨收~今开~成交量(手)~...~涨跌额~涨跌幅%~最高~最低~..."

字段下标（0-based，按~分割）：
- [1]：股票名称
- [3]：最新价
- [4]：昨收
- [5]：今开
- [6]：成交量（手）
- [8]：涨跌额
- [9]：涨跌幅(%)
- [33]：成交额（千元）→ 除以100得亿元
- [44]：PE
- [46]：换手率

注意：主力净流入/量比需从K线数据推算，或单独调用东方财富资金流接口。

#### 主力净流入（东方财富资金接口，可用）
```
GET https://push2.eastmoney.com/api/qt/stock/fflow/kline/get?lmt=1&klt=1&secid={secid}&fields1=f1,f2,f3,f7&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61
Headers:
  Referer: https://quote.eastmoney.com/
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
```
若该接口也被拦截，从K线成交量变化推算量比即可。

### 2. 日K线（近30日，东方财富，无需鉴权）
```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get?fields1=f1,f2,f3,f4,f5,f6&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61&klt=101&fqt=1&secid={secid}&beg=0&end=20500101&lmt=60
Headers:
  Referer: https://quote.eastmoney.com/
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
```

klines 每条格式（逗号分隔）：
日期,开盘,收盘,最高,最低,成交量,成交额,振幅,涨跌幅,涨跌额,换手率

从K线数据计算：
- MA5 = 近5日收盘均价
- MA10 = 近10日收盘均价
- MA20 = 近20日收盘均价
- 5日均量 = 近5日成交量均值
- 近5日是否有涨停（涨跌幅 >= 9.8%）

## 分析步骤

1. 并行请求实时行情 + K线接口
2. 计算均线和量比
3. 按以下维度逐项打分

## 短线评分模型（满分10分）

| 维度 | 指标 | 得分 |
|------|------|------|
| 流动性 | 流通市值50~500亿 | +1 |
| 流动性 | 今日成交额 > 3亿 | +1 |
| 技术面 | 现价 > MA10 | +2 |
| 技术面 | 量比 > 1.5（放量） | +2 |
| 资金面 | 今日主力净流入 > 0 | +2 |
| 强势度 | 近5日内有涨停记录 | +2 |

加减分项：
- 现价距MA10超过8%（追高风险）：-2
- 今日涨幅已超5%：-1（高位追入风险）
- 流通市值 < 20亿或 > 800亿：-1

## 输出格式

```
===== 个股快速评估 =====
股票：XX股份（XXXXXX）
时间：HH:MM

基本行情：
  现价：XX.XX元（今日 +X.XX%）
  成交额：XX.XX亿  流通市值：XX.XX亿
  动态PE：XX倍  PB：X.XX倍

技术面：
  MA5：XX.XX | MA10：XX.XX | MA20：XX.XX
  现价与MA10关系：XX元上方/下方 X.X%
  量比：X.XX（放量/缩量/正常）
  近5日涨停：有/无

资金面：
  今日主力净流入：+/-XX万元

综合评分：XX/10分

结论：【建议关注/可以介入/暂不操作/坚决回避】

操作建议：
  买入区间：XX.XX ~ XX.XX元
  止损位：XX.XX元（买入价 -5%）
  第一目标：XX.XX元（+8%）
  第二目标：XX.XX元（+15%）
  单票仓位上限：10,000元

风险提示：
  - [具体风险点，如追高/流动性不足/技术面偏弱等]
```

## 结论判断规则

- 8~10分：可以介入
- 6~7分：建议关注，等更好的进场点
- 4~5分：暂不操作
- < 4分：坚决回避

## 注意事项

- 非交易时间调用时，f43等字段可能为 "-"，提示用户在交易时段查询
- 若接口返回空，尝试交换secid前缀（部分新股市场代码可能有变化）
- 所有建议仅供参考，最终决策由用户自行判断
