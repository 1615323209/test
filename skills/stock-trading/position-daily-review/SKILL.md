# Position Daily Review（持仓每日复盘）

## 输入
用户需提供持仓信息（每次告诉我）：
- 股票代码 + 持仓成本价 + 持仓数量（或金额）
- 示例："我持有 000069，成本价 12.50元，持仓8000元"

## 数据源

### 实时/收盘行情（腾讯行情，稳定可用）

市场前缀：沪市=sh，深市=sz
```
GET https://qt.gtimg.cn/q={市场前缀}{代码}
Headers:
  Referer: https://gu.qq.com/
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
```

返回~分隔字段，关键下标（0-based）：
- [1]股票名 [3]最新价 [9]涨跌幅% [4]昨收 [33]成交额(千元)

### 日K线（近20日）
```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get?fields1=f1,f2,f3,f4,f5,f6&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61&klt=101&fqt=1&secid={secid}&beg=0&end=20500101&lmt=20
Headers:
  Referer: https://quote.eastmoney.com/
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
```

### 今日市场环境
复用 `short-term-market-scan` 的结论（如当日已执行过）

## 执行步骤

1. 对每只持仓股请求行情 + K线
2. 计算盈亏状态和止盈止损条件
3. 检查技术面是否出现退出信号
4. 结合今日市场环境给出明日操作计划

## 止盈止损判断规则

### 止损触发（满足任一 → 明日开盘清仓）
- 现价低于成本价 -5%
- 现价跌破10日均线（MA10）
- 持仓天数 > 5个交易日且浮盈 < +3%
- 出现以下K线信号：高台跳水、大笔卖出、封跌停板

### 止盈触发
- 浮盈 >= +8%：建议卖出50%仓位
- 浮盈 >= +15%：建议清仓
- 出现以下信号之一：放量大阴线收盘、量比 > 3 且收跌

### 继续持有条件（全部满足）
- 浮盈在 0~8% 之间
- 现价仍在MA10上方
- 今日成交量未异常放大（量比 < 2.5）
- 市场环境评分 >= 3

## 注意事项

- 每次使用时必须告诉我最新持仓（成本价+代码+金额），我不记忆持仓状态
- 若今日大盘评分 <= 1，持仓中的浮盈股建议明日先减仓一半锁利
- 止损是硬规则，不接受"再等一天"的理由
- 所有建议仅供参考，最终决策由用户自行判断
