# 短线交易方法论总纲
## 适用：2万人民币 / 短线（1~5个交易日）/ A股

---

## 一、基本参数（不可变规则）

```
总资金：20,000元

仓位上限：
  单票最大仓位：10,000元（50%）
  最多同时持仓：2只
  底仓现金：至少保留2,000元

止损（硬规则，不得破例）：
  止损幅度：买入价 -5%
  单笔最大亏损：500元（总资金2.5%）
  时间止损：持仓超5个交易日未达+5%，减仓离场

止盈：
  第一目标：+8%（卖出50%仓位）
  第二目标：+15%（清仓剩余）
```

---

## 二、每日操作时间轴

### 09:00~09:25 开盘前——市场环境判断
加载 skill: short-term-market-scan

执行内容：
- 请求财联社大盘指数/涨跌分布
- 请求东方财富板块资金流向
- 请求财联社快讯（有无重大利空）
- 输出今日环境评分（0~5分）及操作建议

判断规则：
```
评分 >= 3 → 可以操作，继续下一步
评分  = 2 → 谨慎，仓位减半（单票上限5,000元）
评分 <= 1 → 今日空仓观望，不操作
```

---

### 09:20~09:30 集合竞价——选股
加载 skill: short-term-stock-pick
前提：环境评分 >= 3

执行内容：
- 从今日主力净流入前3板块中筛选候选股
- 过滤流通市值50~500亿、日均成交额>3亿
- 验证技术形态（10日均线/量比/近期涨停）
- 输出最多3只候选股及评分排名

竞价观察要点：
- 竞价涨幅 > 3% 且量能充足 → 关注
- 竞价下跌 > 2% → 暂时跳过
- 不在竞价阶段追涨，等开盘30分钟后确认方向

---

### 09:30~10:00 开盘黄金窗口——个股确认与进场
加载 skill: stock-quick-analysis
对候选股逐一评估

进场必须同时满足：
```
1. 环境评分 >= 3（已确认）
2. 所在板块当日资金净流入为正
3. 个股评分 >= 6/10
4. 现价未超过当日竞价价格3%以上（不追高）
5. 技术形态满足至少2项（站上MA10/放量/强势）
```

进场动作：
- 分批买入（不一次打满），先买50%仓位
- 若开盘30分钟内走势符合预期，补齐至满仓
- 买入同时在脑中设定止损价（买入价 × 0.95）

---

### 14:30~15:00 尾盘——持仓状态检查
每日收盘前快速检查：

```
触发任一 → 明日处理：
  现价 < 成本价 × 0.95        → 明日开盘止损
  现价跌破MA10                → 明日减仓50%
  持仓 > 5日且浮盈 < +3%      → 明日减仓离场
  出现放量大阴线               → 明日减仓50%

持仓继续条件（全部满足才持有）：
  现价在成本价上方
  现价在MA10上方
  今日无放量异常大阴线
  市场环境评分 >= 3
```

---

### 15:00后 收盘——复盘
加载 skill: position-daily-review
告诉我：股票代码 + 成本价 + 持仓金额

执行内容：
- 获取收盘价和K线数据
- 计算每只持仓的盈亏状态
- 逐项检查止盈止损触发条件
- 输出明日具体操作计划

## 三、选股核心标准（记住这5个）

```
1. 市场环境优先：大盘不对不动
2. 跟着资金走：买主力资金净流入的板块
3. 强者恒强：优先有过涨停记录的强势股
4. 量价配合：放量突破比缩量更可靠
5. 止损是本能：跌5%不犹豫，不找理由扛单
```

---

## 四、绝对禁止事项

```
✗ 大盘跌停/重大利空当日操作
✗ 追涨幅已超5%的个股
✗ 持仓亏损超5%仍继续持有
✗ 单票超过总资金50%（10,000元）
✗ 在没有明确止损位的情况下买入
✗ 因为"感觉要涨"而破止损
✗ 频繁换股（同一天内买卖超过2次）
```

---

## 五、每日复盘记录格式

每日操作结束后，记录以下内容（建议用Obsidian或备忘录）：

```
日期：YYYY-MM-DD
市场评分：X/5
操作记录：
  - 买入：XX（代码）XX元×XX股，原因：XXX
  - 卖出：XX（代码）XX元，盈亏：+/-XX元
今日净盈亏：+/-XXX元
累计盈亏：+/-XXXX元
复盘：今天哪个决策对了/错了，原因是什么
明日关注：XXX板块/XXX股票
```

## 六、月度核查指标

每月底检查这3个数字，若持续恶化需调整方法论：

```
胜率：盈利次数 / 总交易次数（目标 > 50%）
盈亏比：平均盈利 / 平均亏损（目标 > 1.5）
最大回撤：单月最大亏损额（警戒线：总资金10% = 2,000元）
```

若连续3笔亏损 → 强制暂停3个交易日，重新审视市场环境。

## 八、心理准则（最难执行的部分）

```
亏损时：止损不是失败，是保护资金活下去
盈利时：不要贪，到目标价就减仓
冲动时：离开屏幕，10分钟后再决策
连亏时：减少仓位，不要报复性加仓
大涨时：检查是否符合进场条件，不要因为错过而冲动
```

记住：2万资金，保住本金比赚钱更重要。
方法论的价值不在于每笔都赚，而在于让盈利的概率系统性地大于亏损。
