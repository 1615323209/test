# 世界观设定

## 世界观背景

21世纪末，人类天文观测站首次捕捉到不可解的现象——在遥远的深空中，存在着无法用物理学解释的庞大实体。科学家将其命名为"古神"。这一发现被列为最高机密，全球顶尖学者秘密展开研究。

然而观测本身触发了某种古老的规则：被观测的古神苏醒了。

古神的苏醒引发宇宙层级的连锁反应。宇宙开始以不可逆的方式坍缩，星系之间的距离急剧缩短，地球的夜空在短短数年内变得拥挤而陌生。伴随坍缩而来的，是被称为"灾厄"的存在——它们在坍缩的缝隙中涌现，以人类无法理解的方式侵蚀现实。

但坍缩也带来了恩赐。星曜——来自坍缩星系的残余能量——开始洒落地球。少数人类能够感知并吸纳这些能量，获得超越常人的力量。这些人被称为"星曜者"。

世界秩序在短短一代人的时间内彻底崩塌重组。旧有的国家边界模糊了，取而代之的是以星曜者为核心的据点、城邦和势力。

## 修炼体系：十四星曜

共有十四条修炼路径，每条对应一颗主星。星曜者只能选择一条路径，终生无法更改。

| 星曜 | 特性 | 修炼方式 |
|------|------|----------|
| 七杀星 | 杀戮之道，以战养战 | 在战斗中吸纳杀意 |
| 破军星 | 冲锋陷阵，勇猛无匹 | 在绝境中突破 |
| 廉贞星 | 秩序与法则之力 | 制定并遵守规则 |
| 贪狼星 | 欲望与掠夺 | 夺取他人星曜 |
| 紫微星 | 帝王之星，统御万星 | 吸纳信仰 |
| 天府星 | 空间与储存 | 炼化异空间 |
| 武曲星 | 武道极致 | 苦修锤炼 |
| 天相星 | 命运与预知 | 解读星象 |
| 太阳星 | 生命与治愈 | 吸收日光精华 |
| 巨门星 | 防御与守护 | 承受攻击锤炼 |
| 天机星 | 智慧与推演 | 解谜破局 |
| 太阴星 | 隐匿与暗杀 | 在阴影中成长 |
| 天梁星 | 因果与审判 | 代行天道裁决 |
| 天同星 | 和谐与共鸣 | 与他人共鸣共振 |

每条星曜各有九阶，每阶有其独特的阶名（如七杀星第一阶名为"血星"）、能力以及进阶条件。阶名在文中逐步揭示。
