## 关键对账点（E3 vs 网格）
- E3 avg_px = -3.792% vs 网格 turn_ratio 设计段低端 +1.26%
- 对账区间 [+0.9%, +1.5%]: ❌ 未落区间
- **残余口径差定位（v4.2 已查）**:
  1. 网格 = 全市场 rank 选 Top5（无可交易/价格/持仓约束）；回测 = 当日候选池 TOP_N=3 + 50元上限 + 至少100股
  2. E3 关闭动量筛后候选池暴增（不再限 price_pos/ma20），TOP_N 落入**极端低换手股**（网格无此约束未发现其差表现）
  3. 对比: E1（有动量筛）px=+0.086% 方向与网格一致（正），证明**动量筛是"防垃圾股"的必要过滤**而非"规则代价"
  4. 结论: 网格毛收益 +1.26% 在真实回测约束（候选池/价格上限/持仓离散）下不可复现，非口径 bug

## 增量归因（哪条规则最贵）
- E0→E1（退出规则→持满5日）: Δnet +0.249pp → **止损/止盈/MA退出是"割肉规则"，放开后每笔净收益改善**
- E1→E2（择时门→关）: Δnet -0.002pp → 择时门几乎无代价
- E2→E3（动量筛→关）: Δnet **-4.035pp** → **动量筛是"最贵"的规则（防垃圾股的价值最大）**
- E3→E4（单因子→4因子）: Δnet +1.747pp → 4因子组合优于单因子（但仍负）
