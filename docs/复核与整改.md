## P0-3　标着 ICIR 的列不是 ICIR，是 t 值

### 现状

```61:61:code/research/go_nogo_grid.py
            row[hz + "_ICIR"] = round(icm / (np.std(ics) + 1e-12) * np.sqrt(len(ics)), 3) if np.std(ics) > 0 else 0.0
```

`mean/std × sqrt(N)` 是 t 统计量；经典 ICIR 是 `mean(IC)/std(IC)`，不乘 `sqrt(N)`。这就是 `1d_ICIR=-6.821` 与 `1d_t=-7.12` 几乎相同的原因——两列都是 t 值，一列普通一列 Newey-West。同一个错误在 `l1_shortline_factors.py:47`、`l1_lhb_netbuy.py:46` 各有一份。

三个连带后果：L1 文档的 `t_NW ≥ 3` 门槛不能用来读这一列；`illiq_20` 的 22.393 作为 ICIR 荒谬（作为 t 值合理）；总结里"龙虎榜 ICIR +15.2 远超 ma5_dist ICIR -6"这个比较无意义——符号表示方向不表示强弱，且两数来自不同样本。

### 改法

三处统一改为：

```python
        icir = icm / (np.std(ics) + 1e-12)              # 经典 ICIR（日频）
        icir_ann = icir * np.sqrt(252)                   # 年化 ICIR（如需与文献对比）
        t = newey_west_t(ics)                            # 显著性
```

输出列名明确为 `IC / ICIR / ICIR_ann / t_NW`，不要再让 ICIR 和 t 混用。

## P0-4　龙虎榜 rank 构造与"零值当中性"意图相反

### 现状

```19:29:code/research/l1_lhb_netbuy.py

    pl.col("净买额").rank().over("日期").alias("netbuy_rank")
)
...

```

`rank()` 只在**上榜股之间**排，取值 1..N（N≈30-60），未上榜填 0。于是当日净卖出最狠的票拿到 rank 1，**仍高于全部未上榜股票的 0**。所谓"零值当中性"实际是"零值当最低"，全部上榜股（含巨额净卖出）被顶到截面最上方。

而文档自测"上榜后 5 日 -1.011% vs 全市场 +0.157%"——上榜整体利空。把上榜股全顶到顶部，全样本 IC 当然为负。**所以"全样本 IC 为负 → 不做截面 score"这个结论，部分是构造 bug 造出来的。**

### 改法

拆成**两个独立候选因子**分别送漏斗裁决，不要混在一个变量里：

```python
# 因子 A：上榜事件哑变量（方向已知为负，验证"上榜是否利空"）
lhb_event = 1 if 上榜 else 0

# 因子 B：事件内强度，带符号、中性=0（验证"净买 vs 净卖"）
#   优先用比率（需确认 lhb_hist 是否有成交额列）
netbuy_ratio = 净买额 / 成交额
#   无成交额列则用上榜股内 z-score
netbuy_z = (净买额 - mean(净买额).over(日期)) / (std(净买额).over(日期) + 1e-12)
# 未上榜 = 0.0（此时 0 落在上榜股的中位附近，才是真中性）
```

## P1-2　同一笔交易的收益额与收益率来自两套价格口径

```192:197:code/backtest/backtest_engine.py
                    profit = sell_shares*sell_price_cash - sell_shares*h.get('cost_per_share', sell_price) - fee
                    ...
                        'pnl': profit, 'pnl_pct': pnl*100, 'fee': fee,
```

`pnl`（金额）用不复权价差，`pnl_pct` 用复权收益率，两者不可互校。而且不复权价差**把分红当成亏损**——持仓跨除权除息日时股价下跌但收到的现金未记入。5 日持仓下单笔概率约 2%，但送股拆股会造成单笔巨亏假信号。

**改法**：仓位用实盘价、损益用复权收益率，两者一致且自动含分红

```python
        hfq_ret = (sell_price / h['buy_price']) - 1          # 复权收益率（含分红）
        gross   = shares * h['cost_per_share'] * hfq_ret      # 金额与收益率同源
        profit  = gross - fee
```
