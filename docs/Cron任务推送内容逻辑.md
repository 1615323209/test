## 二、短线实盘链（任务 1-5）—— 每日闭环

### 任务 1：每日开盘前市场扫描（09:20）

**触发后动作（四步）**：

1. **市场环境扫描**：并行调财联社大盘接口、东方财富板块资金接口、财联社快讯接口，按 `short-term-market-scan` skill 的评分模型打分
   - `评分 ≤ 2` 或 **非交易日** → 直接输出结论，**不执行后续步骤**（不选股）

2. **知识库辅助判断**（对进入候选的板块/个股）：
   - 板块：读 `板块研究/{板块名}.md`、`市场规律/板块资金轮动观察.md` → 历史资金持续性/假突破记录/风险提示
   - 个股：读 `个股档案/{股票名}.md` → 历史交易记录/特殊规律/风险
   - 文件不存在则跳过

3. **量化因子选股**（L4 实盘信号）：`python D:/quant_project/code/paper/daily_picks.py`
   - v7 因子打分 Top3 候选（代码/打分/市场状态）
   - 这是量化系统的实盘信号，**必须并入今日建议**
   - 脚本报错/数据缺失 → 注明"量化信号暂不可用"并继续盘面选股

4. **短线选股 + 合并输出**：`short-term-stock-pick` skill 对盘面候选综合评分（板块持续性差降 5%、历史亏损⚠️、历史盈利✅）

**推送内容「今日操作建议」（两个来源合并）**：
- **盘面候选**（短线选股）：每只附知识库参考
- **量化候选**（因子打分 Top3）：标注来源"量化因子"
- **两来源重合** → 标注 **⭐双信号**（最高优先级）

**输出格式**：市场环境评分 + 可操作/观望结论 + 建议标的清单（含双信号标记）。

### 任务 2：盘中持股监控（10:30）

**上下文来源**：早上任务 1 的扫描+选股结果已注入。

**动作（按优先级）**：
1. **读真实持仓**：`python live_positions.py --status`；无持仓 → 跳过第二步直接看候选
2. **监控真实持仓（最高优先）**：对每只持仓调腾讯行情 `qt.gtimg.cn/q={sh/sz}{代码}`，按实盘规则：
   - 现价 ≤ 成本×0.95 → **❌ 触发止损，明确建议卖出**
   - 现价 ≥ 成本×1.12 → **🎯 触发止盈，建议分批止盈**
   - 中间 → 报告盈亏，正常持有
3. **监控今日推荐候选**（最多 3 只）：现价 vs 买入区间/止损位、涨幅方向、量比异常

**推送内容【10:30 盘中监控】**：
- 一、真实持仓：每只 `成本|现价|盈亏|状态(✅持有/⚠️接近止损/❌止损/🎯止盈)`
- 二、推荐候选：每只 `推荐价|现价|今日涨跌|状态(✅/⚠️/❌)`
- 一句话总结

**规则**：非交易日仍检查持仓（持仓监控与市场环境无关）；无持仓且非交易日 → "今日非交易日且无持仓，跳过"。

### 任务 3：每日收盘持仓提醒（15:05）

**触发后**：发送收盘提醒，**引导用户用标准格式报告持仓和当日操作**：

```
📊 收盘啦！
今日A股已收盘，请告诉我你的持仓情况和今日操作：
格式：买入 600354 成本12.50 金额8000（或：卖出 600354 200股）
持仓情况：600354，成本12.50，8000元（如有多只请逐只列出）
```

**目的是让用户报告格式**，方便任务 4 用 `live_positions.py --add/--sell` 记录真实持仓。

**非交易日判断**：调 `qt.gtimg.cn/q=sh000001`，涨跌幅为 0 且成交量为 0 → 休市，输出"无需复盘"。

---

### 任务 4：收盘选股复盘沉淀（15:30）

**上下文**：早上选股推荐 + 10:30 盘中监控已注入。

**动作（六步）**：
1. **真实持仓复盘（最高优先）**：`live_positions.py --status` + 腾讯收盘价
   - 记录当日涨跌、累计盈亏、是否触发止损/止盈
   - 用户今日上报买卖 → 先用 `--add/--sell` 更新持仓再复盘
   - 明日计划：止损→卖、接近止损(<-3%)→减仓、止盈→分批、正常→持有
2. **推荐候选复盘**：每只股收盘逻辑是否成立，**失败原因归类 A-E**（板块错/形态失效/环境变/标准缺陷/时机不对）
3. **写每日复盘**：追加 `每日复盘/daily_review.md`（市场环境 + 真实持仓表 + 推荐标复盘表 + 总结）
4. **更新个股档案**：`个股档案/{股票名}.md` 交易记录
5. **更新板块研究**：`板块研究/{板块名}.md` 历史表现记录
6. **推送简报**：

**推送内容【收盘复盘】**：
```
真实持仓：X只 | 当日盈亏：±XX元
- 600354：成本12.50 → 收盘13.10（+4.8%）✅持有 / ❌触发止损，明日卖出
推荐命中：X/X只
{每只：名称 推荐区间→收盘价 ✅/❌ 失败原因}
知识库已更新：个股档案 X 条 | 板块研究 X 条
```

**规则**：无持仓且无推荐 → "今日无操作，跳过复盘"，不写文件。

### 任务 5：每周策略回顾与迭代（周五 15:45）

**动作（五步）**：
1. **读本周复盘**：`每日复盘/daily_review.md` 提取周一~今天数据；无记录 → "跳过迭代"
2. **统计 4 条件命中率**（命中=推荐股当日或次日收盘涨>0%）：
   - A 板块资金（40%）｜B 放量突破（20%）｜C 站上均线（20%）｜D 近期涨停（20%）
3. **算新权重**（单次调 5%，范围 10~60%）：
   - 命中率 < 40% 且样本 ≥2 → -5%，补给最高
   - 命中率 > 80% 且样本 ≥2 → +5%，从最低扣
4. **更新知识库**：
   - 权重变化 → patch `short-term-stock-pick` skill 权重表（+注释行）
   - 追加 `策略演化/选股权重变更记录.md`
   - 更新 `市场规律/板块资金轮动观察.md`（样本≥10 条算结论）
   - 某失败原因连续 ≥3 次 → `daily_review.md` 末尾加"持续失误提醒"
5. **推送周报**

**推送内容【📈 本周选股策略周报】**：
```
本周战绩：推荐X只|命中X只|命中率X%
各条件表现：A/B/C/D 各自 X/X（X%）→ {调整/不变}
主要失误：...
下周策略调整：...
知识库已更新：策略演化|市场规律|{权重变化时}skill权重已自动修正
```

## 三、量化研究系统（任务 6、7）—— 独立自动跑

### 任务 6：每日量化数据更新（15:40 周一至五，no_agent 脚本）

**脚本**：`scripts/quant_data_update.py` → 依次调：
1. `paper/update_hs300.py`（沪深300 指数增量）
2. `paper/update_daily.py`（全市场行情采集 + 因子重算 + 市场情绪）

**逻辑**：幂等（数据已最新则跳过）；把所有输出精简为关键行（已更新/无需更新/股票数/采集行数）。数据为次日早盘量化选股准备。

### 任务 7：量化因子挖掘 loop（每 2 小时，no_agent 脚本）

**脚本**：`scripts/quant_loop_cron.py` → `loop/run_loop_cron.py` → `python -m loop.factor_mining_loop --batch 1 --n-cands 2`

**逻辑**：L1-G0-G4 漏斗挖因子：
- LLM 生成候选（C1 复现 anomaly + A股适配）→ G0 静态沙箱 → G1 抽样 → G2 主周期（t_NW≥3 + 声明符号）→ G3 完整 → G4 留出确认 → L2 筛选 → 入池
- cron 每 2 小时跑 **2 个候选**（约 6-9 分钟，控制在超时预算内）
- **推送内容**：挖掘摘要（候选数/漏斗各门拦截数/入池数）+ dashboard 健康分；无产出也推送状态

## 四、任务衔接与数据流

```
09:20 双源选股 ──→ 10:30 盘中监控（注入早盘结果）
  │                    │
  └── 推荐标的 ────────┘→ 15:05 收盘提醒（引导报告持仓）
                                    │
15:40 数据更新（为次日）← 15:30 复盘沉淀（记录真实持仓+候选）
                                    │
                             周五 15:45 周迭代（调 skill 权重）
```

**共享数据文件**：
- 真实持仓：`D:/quant_data/live_positions.json`（任务 2/4 读写）
- 真实成交：`D:/quant_data/live_trades.csv`（L4 SPRT 数据源）
- 因子打分：`D:/quant_data/daily_picks/`（任务 1 读）
- 知识库：`每日复盘/策略演化/市场规律/板块研究/个股档案`

## 五、异常与降级处理

| 场景 | 处理 |
|------|------|
| 市场评分 ≤2 / 非交易日 | 任务 1 不选股；任务 3 提示休市 |
| 量化脚本报错/数据缺失 | 任务 1 注明"量化信号暂不可用"，仅走盘面 |
| 无持仓 | 任务 2/4 跳过持仓环节，只看候选 |
| 无成交记录 | run_l4 登记观察，不做 SPRT 判定 |
| cron 脚本超时 | 已调至 600s；挖掘 loop 用 2 候选/批控制时长 |
| 数据源失效（GFW/采集失败） | 数据健康门禁暂停 loop + 告警，不自动跳过 |
