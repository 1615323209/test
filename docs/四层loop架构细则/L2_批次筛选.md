## 一、定位与边界

L2 是因子质检层。**L1 已完成全部单因子体检**（多周期 IC、覆盖率、可交易域一致性、Top-K 精度、quintile 单调性、风格中性残差 IC、信号自换手），L2 不再重复这些，只做**依赖因子池上下文**的判断：与池内因子是否冗余、对现有策略是否有增量、生命周期多长、跨 regime 是否稳定。

**分工原则**（2026-08-17 修订，与 L1 第一章一致）：判断依据是"是否依赖池上下文"。

|归属|内容|
|---|---|
|**L1**（单因子性质）|多周期 IC、覆盖率、可交易域、Top-K 精度、quintile 单调、风格中性、信号自换手|
|**L2**（池上下文）|三通道去重、动态正交化、regime 分层、半衰期、持仓换手暴露|

原分工把 quintile 单调性放在 L2，导致"IC 漂亮但头部平坦"的候选要等到 L2 才被拦，白白消耗了去重与正交化两次全表运算。

## 二、输入与批次

- **输入**：L1 交付的 `FactorCandidate`（契约见 L1 第三章）+ 全量 L1 指标
- **批次**：默认 5 候选/批（可配）✅
- **必须透传给 L3 的字段**（🔧P1）：`role`、`label_spec`、`declared_direction`、`n_peek`、可交易域指标、Top-K 指标——其中 `n_peek` 是 L3 多重检验 N 的输入（见 L3 第五章）

**按 `role` 分流**（🔧P2）：

|role|L2 处理方式|
|---|---|
|`score`（选股打分）|走完整管线（第四章）|
|`exit`（出场/存活）|只做语义/数值去重 + 档案登记；正交化、regime、半衰期都是"打分因子"的概念，不适用|
|`timing`（因子择时）|只做去重 + 档案登记|

`role != "score"` 的候选**不进打分池**，直接交 L3；L3 对应评估形态未就绪前只登记档案（与 L3 第三章 3.4 一致）。

## 三、数据口径（🔧P1，与 L1 的样本切分对齐）

L1 把训练集切成设计段 2021-2023 与内层留出 2024（L1 第二章）。L2 必须遵守同一约定，否则 2024 会被 L2 消费掉，L1 的 G4 确认就失去意义。

|用途|区间|理由|
|---|---|---|
|**判定类**（去重相关、正交残差、regime、换手暴露）|设计段 2021-2023|任何"决定去留"的检验都是选择行为，必须与 L1 同段|
|**描述类**（半衰期、档案指标）|2021-2024|不做通过/拒绝判定，只影响标记与 L3 权重上限，需要更长序列|
|**禁止**|2025-2026|宪法：L1/L2 不可见验证集|

现状全部用整训练集 2021-2024 ⚠️（见第九章缺陷 8）。

## 四、筛选管线（顺序执行，任一不过即拒）

```
换手暴露 → 三通道去重 → 动态正交化 → regime 分层 → 半衰期
```

> **反因子检验已废除**（原管线最后一环），理由见第五章。

### 1. 换手暴露（选股风格）✅

- 换手暴露 = Top10% 日 `turn_ratio` 均值 / 全市场均值，**≤ 1.5**
- 口径按"5 日调仓"验证（与 L3 第六章一致）
- **与 L1"信号自换手"的区别**（必读，两者常被混为一谈）：

|指标|层|测什么|决定什么|
|---|---|---|---|
|信号自换手（rank 自相关）|L1 G3|因子值本身翻动多快|交易成本、能否适配 5 日周期|
|换手暴露|L2|选出来的股票是不是高换手股|风格暴露、流动性风险|

两者都要，含义不同，不可互相替代。

- **quintile 单调性已上移 L1 G3**（🔧P1）。L2 只保留一项：`extreme_driven` 标记因子的头尾一致性**与池内同类因子对比**复核（这一项依赖池上下文，留在 L2）

### 2. 三通道去重（全部通过才放行）

|通道|方法|阈值|状态|
|---|---|---|---|
|线性冗余|Pearson|\|ρ\| < 0.7|✅|
|单调非线性|Spearman|\|ρ\| < 0.7|✅|
|语义冗余|`expr_hash`（归一化后 hash）|池内不命中|✅|
|一般非线性|归一化互信息 MI|< 0.3|⚠️ 代码未实现|

- **🔧P1 相关性口径修正**：现状对随机抽样 20 万行做**池化相关**（`df.sample(n=200_000)`）。池化相关混入了时序共同波动——两个横截面上并不冗余、但同期涨跌同步的因子会被误判为重复，反之亦然。应改为**逐日横截面相关的时间均值**（与 IC 同一套算法）
- **🔧P1 与 L1 已拒绝库联动**：L1 的 G0 已做过语义去重（候选 vs 历史拒绝库），L2 的语义通道只需负责"候选 vs 池内因子"，不要重复

### 3. 动态正交化（随池子增长）

- 基准 = **v7 六因子 + 池内全部"启用/候选"因子**✅（不只是 v7）
- 残差显著才通过；残差不显著 → "已被现有池子解释"拒绝
- **数值稳定性** ✅：池 ≥10 因子时禁用裸 lstsq → 岭回归（α=1e-3~1e-2）或 PCA 截断（95% 方差）；先测条件数，cond > 1e6 自动切换
- ⚠️ **重大口径缺陷**：现状 `resid_icir = corr(resid, y) × 10` 是量纲上的拍脑袋近似，不是 ICIR；且数值异常时 `return True`保守放行，实际拦截力很弱。**修正**（🔧P1）：残差列 → 逐日横截面 Spearman IC 序列 → Newey-West t（与 L1 同口径），门槛 **t_NW ≥ 2.0**（对应旧口径"残差 ICIR ≥ 0.2"的严格度，需用 v7 六因子回归校准）
- 🔧P1 **基准形式要与 L3 打分一致**：L3 注入池内因子时用的是 `(expr).rank().over('日期')`，而 L2 正交化基准用的是原始 expr。两者不一致会让"残差"的含义与策略实际使用的信号脱节——正交化基准应统一改为 rank 形式

### 4. Regime 分层

- 训练集按 **沪深300 MA20 + 涨停家数** 分牛/熊/震荡三态
- 三态 IC 方向一致且 |ICIR| ≥ 0.15 → 通过（防"全周期达标、单边市运气"）
- 🔧P0 **这一关目前完全失效**：`l2_regime` 从未把候选表达式物化成 `_cand` 列，`select(["日期","_cand",...])` 必然抛 ColumnNotFound，而异常分支是 `return True, {}` → **任何因子都能通过，且 regime 指标恒为空**。日志里 `regime={}` 即该症状（见第九章缺陷 1）
- ⚠️ 即便修好物化问题，现状也只实现了**牛/熊两态**（`bull = close > ma_20`），`涨停家数` 读进来了但没用于三态划分；文档写三态、代码两态
- 🔧P1 每态样本量下限 >100 天 ✅已有；口径改设计段

### 5. 半衰期分析

- 滚动 252 日 ICIR 线性拟合斜率 → 半衰期（月）✅（**描述类**，用 2021-2024）
- **< 6 月 → 标记 `short_lived`**：L4 评估周期缩到 10 交易日，L3 权重封顶 0.04 ✅
- ⚠️ 数据不足或异常时返回 12.0（默认长寿命）= **乐观兜底**，会让算不出半衰期的因子拿到最高权重上限。🔧P1 改为返回 `None` 并标记 `half_life_unknown`，L3 按 `short_lived` 保守处理

## 五、废除项：反因子检验（🔧P0，文档级修正）

原第三节第 6 环：构造 `-expr`，要求反向因子 |ICIR| ≥ 0.25 且与原因子 |ICIR| 差异 < 30%。

**这个检验在数学上恒等成立**：Spearman rank IC 对取负是精确反号，`corr(-f, y) = -corr(f, y)`，因此 |ICIR| 完全相同、差异恒为 0。凡是过了 L1 主周期门槛的因子必然通过这一关，纯粹白跑一次全量 IC 计算。

**替代方案**：其原本意图（验证信号方向性真实存在，而非噪声方向漂移）已由 L1 覆盖——

- L1 G3 的 **Top-K 精度 + Top-K 稳健性**（头部超额显著、K 三档同号）
- L1 G3 的**分年符号一致性**
- L1 G2 的**声明符号一致**（`declared_direction`，事前声明方向）

若仍想在 L2 补一个池上下文视角的方向性检验，可选（🔧P2）：**子样本符号一致性**——按市值/行业分组后各组 IC 符号一致。这依赖池外分组信息，适合放 L2。

**结论：直接废除，不做替代实现。**
