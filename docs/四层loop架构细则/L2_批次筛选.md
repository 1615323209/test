# L2 批次筛选（第二层）

> 所属：四层 loop 第二层 ｜ 宪法第二章（架构）+ 实现细则第三章（数值）
> 职责：**"哪些值得留"**——精算、去重、正交化、regime/半衰期/反因子验证，合格才入池
> 衔接：L1 合格候选 → L2 筛选 → 入池（状态=候选）→ 触发 L3

---

## 一、定位

L2 是因子质检层。L1 只看了单因子 IC，L2 把它放进"因子池上下文"检验：与池内因子是否冗余、对策略是否增量、生命周期多长、方向是否真实。

## 二、批次

- 默认 5 候选/批（可配）

## 三、筛选管线（顺序执行，任一不过即拒）

```
精算层 → 三通道去重 → 动态正交化 → regime分层 → 半衰期 → 反因子
```

### 1. 精算层（换手 + 单调性）
- 换手暴露 = Top10% 日 turn_ratio 均值 / 全市场均值，**≤ 1.5**
- quintile 单调性 **|mono| ≥ 0.3**（LLM/黑箱因子 ≥ 0.5；extreme_driven 因子复核头尾一致性）

### 2. 三通道去重（全部通过才放行）
| 通道 | 方法 | 阈值 |
|------|------|------|
| 线性冗余 | Pearson | \|ρ\| < 0.7 |
| 单调非线性 | Spearman | \|ρ\| < 0.7 |
| 语义冗余 | expr_hash（归一化后 hash） | 池内不命中 |
| 一般非线性（补充） | 归一化互信息 MI | < 0.3 |

### 3. 动态正交化（随池子增长）
- 基准 = **v7 六因子 + 池内全部"启用/候选"因子**（不只是 v7）
- 残差 ICIR ≥ 0.2 才通过；残差不显著 → "已被现有池子解释"拒绝
- **数值稳定性**：池 ≥10 因子时禁用裸 lstsq → 岭回归（α=1e-3~1e-2）或 PCA 截断（95% 方差）；先测条件数，cond > 1e6 自动切换

### 4. Regime 分层
- 训练集按 沪深300 MA20 + 涨停家数 分牛/熊/震荡三态
- 三态 IC 方向一致且 |ICIR| ≥ 0.15 → 通过（防"全周期达标、单边市运气"）

### 5. 半衰期分析
- 滚动 252 日 ICIR 线性拟合斜率 → 半衰期（月）
- **< 6 月 → 标记 short_lived**：L4 评估周期缩到 10 交易日，L3 权重封顶 0.04

### 6. 反因子检验
- 构造 -expr，要求反向因子 |ICIR| ≥ 0.25 且与原因子 |ICIR| 差异 < 30%
- 验证信号方向性真实存在（非噪声方向漂移）

## 四、因子档案（入池记录）

```
{expr, expr_hash, version_chain, logic, narrative,
 ic_metrics, fine_metrics, regime_metrics,
 half_life, reverse_metrics, batch_id, timestamp}
```

- **版本链**：修正轮 v1→v2→v3 全保留，入库挂最新版，回滚可回溯旧版
- **叙事**：必须含一句话经济解释（narrative），供人工评审与归因

## 五、产出

- 通过者入池：状态=**候选** → 写检查点（batch 粒度）+ 批报告
- 候选池攒够 3 个 → 触发 L3
