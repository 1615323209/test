## 一、定位

L4 是最终裁判层。回测再好也要实盘说话——用**真实成交**对比回测预期，SPRT 序贯检验保证样本不足时不乱下结论，regime 感知避免把"市场变天"误判成"因子失效"。

## 二、触发与周期

- 触发：L3"确认启用"的因子，下一交易日进入实盘打分（`daily_picks.py` 注入）
- 样本分级：

|因子类型|正式判定所需样本|
|---|---|
|正常因子|≥20 交易日 + ≥10 笔成交|
|short_lived 因子（半衰期<6月）|10 交易日 + ≥5 笔|
|**`half_life_unknown`**（L2 半衰期算不出，🔧P1）|同 short_lived：10 交易日 + ≥5 笔|
|早期预警（≥5 笔不足正式）|只告警不回滚（偏差超 2 倍阈值才提示）|

> `half_life_unknown` 的处置原则：**算不出半衰期不等于长寿命**。L2 现状异常兜底返回 12 月（乐观），会让这类因子同时拿到 L3 最高权重上限和 L4 最长观察期——两头都偏松。修正后按短寿命保守处理（L2 第四章第 5 节、L3 第四章）。

## 三、SPRT 序贯检验（核心判定）

```
H0: μ₀ = 0（无超额收益）
H1: μ₁ = L3 回测预期收益（降级因子 μ₁ = 0）

每笔成交收益 xᵢ ~ N(μ, σ²)，σ 滚动估计（样本不足用基线回测收益标准差作先验）

ln(LR) = Σ [(xᵢ-μ₀)² - (xᵢ-μ₁)²] / 2σ²

边界（α=β=0.05）：
  A = ln(0.95/0.05) ≈ +2.94
  B = ln(0.05/0.95) ≈ -2.94

ln(LR) ≥ A → 确认启用
ln(LR) ≤ B → 回滚
B < ln(LR) < A → 继续观察
```

**为什么用 SPRT**：固定样本检验（如"5 笔就定性"）置信区间极宽。SPRT 每新增一笔就更新似然比，达到 95% 置信度才决策——样本少时自动延长观察，杜绝误判。

## 四、偏差检测（regime 感知 + 绝对值地板）

```
偏差 = (实盘收益 - 预期收益) / max(|预期收益|, 2.0%)
                                        ↑ 2% 绝对值地板（防除零/微小预期放大）
```

|检测项|正常阈值|
|---|---|
|收益偏差|≤ ±50%|
|胜率偏差|≤ ±15pp|
|方向性|实盘收益符号与预期一致|

**regime 判定**（偏差超阈值时）：

1. 先查当前市场状态（沪深300 MA20 / 涨停家数）
2. 与回测时 regime 不同 → 标记"regime 切换"：暂缓处置，观察至同 regime 重现或满 40 交易日
3. 同 regime 下仍偏差 → 判定"因子失效"：回滚 + 告警

### 按 `role` 区分偏差口径（🔧P2，与 L1 契约 / L3 三形态对齐）

上表的"收益偏差 / 胜率偏差"只对**选股打分因子**有意义。`exit` 与 `timing` 因子没有对应的选股交易，套用同一口径会得出无意义的结论。

|role|偏差定义|判定阈值|
|---|---|---|
|`score`（选股打分）✅|(实盘收益 − 预期收益) / max(\|预期收益\|, 2.0%)|见上表|
|`exit`（出场存活）🔧P2|**实盘出场时点 vs 回测出场时点的差异**：同一持仓在实盘触发出场的交易日与回测触发日之差（交易日数），以及由此产生的收益差|出场时点偏差 ≤ ±2 个交易日；因时点差异导致的收益损失 ≤ 1%|
|`timing`（因子择时）🔧P2|**权重切换点在实盘的表现**：实盘切换时点与回测切换时点是否一致，切换后 20 日收益方向是否与预期一致|切换时点一致率 ≥ 70%；切换后收益方向一致|

补充要求：

- `exit` 因子的 SPRT 观测量改为**每笔出场的收益差**（而非每笔成交的绝对收益），H0 = 出场规则无改善
- `timing` 因子样本以**切换点**计数，而非成交笔数；切换点 < 5 次一律"观察"，不做判定（与 L3 第 3.3 节的 <10 次判样本不足呼应，L4 阈值更低是因为实盘样本天然更少）
- 三类因子的回滚 reason 必须写明所用偏差口径，防事后复盘时口径混淆

## 五、判定规则

|情形|状态|
|---|---|
|偏差在阈值内 且 SPRT 达置信|**实盘确认**（长期保留）|
|偏差超阈值 且同 regime 且 SPRT 达置信|回滚（移除 + 告警 + reason）|
|偏差超阈值 但 regime 已切换|观察（暂停打分，不立即回滚）|
|SPRT 未达置信|观察（继续收集样本）|

## 六、降级验证因子（与小样本降级联动）

- L3 验证集小样本降级通过的因子（degraded_enabled）→ L4 预期基准**直接下调为 0**（实盘不亏即算赢）
- 日志标记"降级验证启用"，观察频率提高（每 10 交易日复核）

## 七、权重微调

- 实盘确认后可做一次权重微调（上限 ±50%）
- **调整后必须重新过 L3 验证**（防过拟合）

## 八、加仓门槛（贴合2万资金）

```
实盘连续 3 个月：
  最大回撤 ≤ max(基线回撤+3%, 8%)    ← 基线-5.68% → 门槛-8.68%
  且 3 个月累计收益不为负
跑输 v7 基线收益 20% 以上 → 人工评审是否终止实盘
全部达标 + 人工批准 → 提高单票上限 / 扩大资金
```
