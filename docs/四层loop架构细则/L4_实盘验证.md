## 一、定位

L4 是最终裁判层。回测再好也要实盘说话——用模拟盘实际成交对比回测预期，SPRT 序贯检验保证样本不足时不乱下结论，regime 感知避免把"市场变天"误判成"因子失效"。

## 二、触发与周期

- 触发：L3"确认启用"的因子，下一交易日进入模拟盘打分（daily_picks.py 注入）
- 样本分级：

| 因子类型 | 正式判定所需样本 |
|---------|----------------|
| 正常因子 | ≥20 交易日 + ≥10 笔成交 |
| short_lived 因子（半衰期<6月） | 10 交易日 + ≥5 笔 |
| 早期预警（≥5 笔不足正式） | 只告警不回滚（偏差超 2 倍阈值才提示） |

## 三、SPRT 序贯检验（核心判定）

```
H0: μ₀ = 0（无超额收益）
H1: μ₁ = L3 回测预期收益（降级因子 μ₁ = 0）

每笔成交收益 xᵢ ~ N(μ, σ²)，σ 滚动估计（样本不足用基线回测收益标准差作先验）

ln(LR) = Σ [(xᵢ-μ₀)² - (xᵢ-μ₁)²] / 2σ²

边界（α=β=0.05）：
  A = ln(0.95/0.05) ≈ +2.94
  B = ln(0.05/0.95) ≈ -2.94

ln(LR) ≥ A → 确认启用
ln(LR) ≤ B → 回滚
B < ln(LR) < A → 继续观察
```

**为什么用 SPRT**：固定样本检验（如"5 笔就定性"）置信区间极宽。SPRT 每新增一笔就更新似然比，达到 95% 置信度才决策——样本少时自动延长观察，杜绝误判。

## 四、偏差检测（regime 感知 + 绝对值地板）

```
偏差 = (实盘收益 - 预期收益) / max(|预期收益|, 2.0%)
                                        ↑ 2% 绝对值地板（防除零/微小预期放大）
```

| 检测项 | 正常阈值 |
|--------|---------|
| 收益偏差 | ≤ ±50% |
| 胜率偏差 | ≤ ±15pp |
| 方向性 | 实盘收益符号与预期一致 |

**regime 判定**（偏差超阈值时）：
1. 先查当前市场状态（沪深300 MA20 / 涨停家数）
2. 与回测时 regime 不同 → 标记"regime 切换"：暂缓处置，观察至同 regime 重现或满 40 交易日
3. 同 regime 下仍偏差 → 判定"因子失效"：回滚 + 告警

## 五、判定规则

| 情形 | 状态 |
|------|------|
| 偏差在阈值内 且 SPRT 达置信 | **实盘确认**（长期保留） |
| 偏差超阈值 且同 regime 且 SPRT 达置信 | 回滚（移除 + 告警 + reason） |
| 偏差超阈值 但 regime 已切换 | 观察（暂停打分，不立即回滚） |
| SPRT 未达置信 | 观察（继续收集样本） |

## 六、降级验证因子（与小样本降级联动）

- L3 验证集小样本降级通过的因子（degraded_enabled）→ L4 预期基准**直接下调为 0**（实盘不亏即算赢）
- 日志标记"降级验证启用"，观察频率提高（每 10 交易日复核）

## 七、权重微调

- 实盘确认后可做一次权重微调（上限 ±50%）
- **调整后必须重新过 L3 验证**（防过拟合）

## 八、升实盘门槛（贴合2万资金）

```
模拟盘连续 3 个月：
  最大回撤 ≤ max(基线回撤+3%, 8%)    ← 基线-5.68% → 门槛-8.68%
  且 3 个月累计收益不为负
跑输 v7 基线收益 20% 以上 → 人工评审是否终止实盘
全部达标 + 人工批准 → 小资金实盘
```
