# L1 单因子精炼（第一层）

> 所属：四层 loop 最内层 ｜ 宪法第二章（架构）+ 实现细则第二章（数值）
> 职责：**"这个因子行不行"**——LLM 生成候选，多周期 IC 体检，不合格直接淘汰
> 上层衔接：L1 输出合格候选 → L2 批次筛选

---

## 一、定位

L1 是因子入口层。DeepSeek 按金融逻辑生成因子表达式，系统自动完成列名校验、PIT 检查、多周期 IC 体检，不合格的因子在入口就淘汰（不浪费上层算力）。

## 二、输入

- LLM 生成的一个候选因子：`{name, logic, narrative, expr}`（polars 表达式）

## 三、执行流程

```
LLM 生成 → 列名校验 → PIT 检查 → 多周期 IC → 反馈 LLM → 重算(≤3轮)
                                              ↑_____________|
```

1. **列名校验**：expr 引用的列必须 ∈ ic_data schema，幻觉列名直接拦截
2. **PIT 一致性检查**：非量价列（财务/行业/ST）随机抽 5 个历史日期对照 PIT 快照，违反即拦截
3. **多周期 IC**：fwd_1d/5d/10d/20d 四个预测期全部计算 Spearman IC（训练集口径）
4. **反馈 LLM**：多周期 IC / ICIR / IC>0 占比 / 同号段 / last2_ok → 要求修改
5. **修正轮**：最多 3 轮；|ICIR| 比首轮低 20% 以上提前放弃

## 四、过线标准（全部满足）

| 检查项 | 阈值 | 目的 |
|--------|------|------|
| 主周期 fwd_5d | \|ICIR\| ≥ 0.25 | 基本显著性 |
| 次周期同号 | fwd_1d/10d/20d 与主周期同号 | 信号跨周期一致 |
| IC 衰减 | \|IC_5d\|→\|IC_10d\| 衰减 < 50% | 防瞬时脉冲假因子 |
| IC 稳定性 | 滚动 60 日 ICIR min > 0 | 防近期才有效的过拟合 |
| Rank vs Normal | 同号；异号需 \|Normal\|≥2×\|Rank\| 且同向 | 重尾容忍 |
| 同号段比例 | seg_ok_ratio ≥ 60% | 分段稳定 |
| 最近两段 | last2_ok = True | 未端不反向 |

## 五、关键机制

### Determinism 控制（可复现）
- seed = `batch_id × 1000 + factor_idx`
- 记录 model_version / temperature / seed 到 l1_log.csv
- 支持按 seed 重放完整修正轨迹（复盘/审计）

### 列名黑名单（幻觉高频）
成交量、成交额、收盘价、开盘价、最高价、最低价、收益率、涨跌幅、涨幅、volume、close、open

### 重尾容忍（Rank vs Normal 异号时）
- 异号但 \|Normal IC\| ≥ 2×\|Rank IC\| 且方向一致 → 通过，标记 `extreme_driven`
- 该标记要求 L2 必须复核 quintile 头尾单调性（防极值单点驱动）

## 六、输出

- 合格：因子 + 全量 IC 指标（多周期 × 双口径）→ 进入 L2
- 不合格：记录拒绝原因丢弃

## 七、监控落盘

`loop_state/l1_log.csv`：候选数、解析成功率、幻觉拦截数、PIT 拦截数、多周期 IC、衰减曲线、滚动 ICIR min、Rank vs Normal 符号、平均修正轮数、放弃原因

## 八、生成方式：三大前沿方向（L1 方法论）

基于两轮挖掘的教训（v1 2340 候选高度冗余、独立主题仅 4-5 个、v2 新因子边际价值有限），**放弃"两两组合+IC 筛选"式穷举**，L1 的因子来源转向 2023-2024 兴起的三大前沿方向：

### 方向一：AI 大模型生成因子（LLM-based Synthesis）—— 首选，已落地

利用大语言模型（DeepSeek）的推理能力"发明"因子，核心是 **Prompt → 代码生成 → 回测反馈 → 自我修正** 闭环：

1. **Prompt Engineering**：告诉 LLM "我有 OHLCV 数据 + 45 个现有因子，请根据金融逻辑生成可能预测未来 5 日收益的因子公式，需使用 Polars 语法"——数据字典（列名/含义）喂进去
2. **代码生成**：LLM 输出 Polars/Python 表达式，直接可跑
3. **回测反馈**：系统自动执行代码计算 IC（复用多周期 IC 管线），把 IC 结果和报错信息返回给 LLM
4. **自我修正**：LLM 思考"为什么这个因子 IC 是负的？请修改公式以优化 IC"——多轮迭代（≤3 轮）

**优势**：因子带金融逻辑（如"主力吸筹"），可解释、多样，跳出纯数学拟合的黑箱。

**实现**：`llm_factor_synth.py`（DeepSeek API，数据字典从 ic_data schema 自动生成）；每候选 ≤3 轮修正，ICIR 仍 <0.2 则丢弃；数据字典可扩展（基本面/资金流列）给 LLM 更多原料。

### 方向二：深度学习表示学习（Alpha360 / Alpha158 进阶）

不再显式生成公式，让神经网络自动学习特征：原始序列 → 网络 → 特征向量（即"因子"）。

| 代表架构 | 做法 | 适用 |
|---------|------|------|
| Alpha360 | CNN 处理 30 天 K 线序列 | 序列模式识别 |
| GRU-GBDT | GRU 提取时序特征 → XGBoost 预测 | 混合特征 |

**关键约束（必须遵守）**：日频纯量价数据上，不加极强正则化必过拟合（回测上天、实盘落地）。业界用**对抗学习 / 信息瓶颈**约束网络学普适规律。高频/另类数据（逐笔、舆情）效果远好于日频量价。

**实现**：从 `a_stock_daily_hfq.parquet` 构造 30 天×特征 张量（16GB 内存可行）；定位是产出特征向量喂给 v7 打分做增量，不替代 v7；严格 walk-forward 外推验证；需安装 torch 或 lightgbm/xgboost。

### 方向三：强化学习公式生成 —— 稀有但高潜力

Agent = "公式生成器"：Action 选算子（ts_rank/corr 等）、State 是公式树结构、Reward 是计算的 IC。训练 Agent 学会"搭积木"最大化 IC，比遗传规划聪明——能记住哪些算子组合过去有效，避免无效随机搜索。

**实现**：复杂度最高，作为方向一的后续演进；候选算子库：ts_rank / ts_corr / ts_std / ts_min_max / rolling_quantile 等 polars 内置时序函数；简化起步用 beam search（保留 Top-K 公式树）代替完整 RL，验证 Reward=IC 的可行性。

### 通用门槛（任何来源的新因子必须过，已在第四节固化）

1. 多周期 IC 四关（|ICIR|≥0.25 + 同号段≥60% + last2_ok + 衰减/稳定性/Rank）
2. quintile 单调性 |mono|≥0.3（LLM/深度因子尤其要查——黑箱因子最易出现"极端层信号、中间层噪声"）
3. **对 v7 有增量**：动态正交化残差 ICIR 仍显著（见 L2 文档）
